# TrekHAOS

TrekHAOS runs the upstream [TREK trip planner](https://github.com/liketrek/TREK) as a Home Assistant app.

Add the repository URL from the [main README](../../README.md), install TrekHAOS from the app store, then follow [DOCS.md](./DOCS.md) to finish setup.

The app icon is the official [TREK project icon](https://github.com/liketrek/TREK/blob/main/docs/trek-icon.png).
